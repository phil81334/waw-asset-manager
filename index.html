About WaW Asset Manager

      

        
An unofficial tool made for the World at War modding community.

        

          Edit Modtools GDT assets and prepare PNG/TGA texture inputs, using the
          original installed Treyarch converter. Original images are kept. GDT
          edits are saved to the selected file. Compiled outputs are written
          directly by Treyarch's converter.
        

        

          CGFX automation, 16-bit PNG, shader previews and automatic PBR
          conversion are not included. Requires World at War and its Modtools.
          Independent of Treyarch, Activision and UGX.
        

        

          Built with JavaScript, Vite, Rust and Tauri. Open source under
          GPL-3.0; see ATTRIBUTION.md.
